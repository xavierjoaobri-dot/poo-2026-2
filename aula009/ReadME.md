
# Pet Shop | O banho e a tosa do Bento

## Integrantes
- Laura B.
- João O.

## Descrição
Programa desenvolvido em Java para controlar os
serviços de banho e tosa de um animal

## Classes utilizadas
- Animal: guarda os dados do animal e do tutor
- Servico: classe abstrata dos serviço
- Banho: calcula o preço do banho
- Tosa: calcula o preço da tosa
- Atendimento: controla a situação dos serviços
- Main: executa o programa

## Como executar
1. Abra o projeto em Java
2. Execute o arquivo Mainjava
3. Observe os resultados no terminal

## Conceitos utilizados
- Encapsulamento
- Herança
- Polimorfismo
- Sobrescrita de métodos (@Override)
- Construtores
